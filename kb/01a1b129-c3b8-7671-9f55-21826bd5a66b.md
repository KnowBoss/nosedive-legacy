# Hydrate repo.workspace

## Usage

Legacy's `hydrate-repo.workspace` on core's hydrate-repo. `<repo>` is a registered repo doc's quid or exact name; a name two docs share is refused naming both.

Without `--at`, the checkout is core's: detached at trunk, read-only. With `--at <ref>`, core hydrates it at trunk, then it is detached at the ref, fetched from origin when the cache lacks it. An existing checkout is left where it is, saying when it is not at the ref asked for.

`--read-only` is accepted for legacy's callers and changes nothing: a checkout without a feat never has a branch to push.
