# Record.gate

## Usage

Legacy's `record.gate` (its command doc `2c678acb`), minting only. Writes, in one commit to the hero:

- a doc of the hero's `gate` kind with `meta.test-script: kb/artifacts/<gate id>.mjs`, its name `--name` or else made from the gist;
- that script, a stub whose `run` writes the gate's id to stderr and returns `false`, so an unwritten gate is red;
- a link to the gate on `<feat>`, rel `test.gate`, or `land.gate` with `--action land`, carrying `test-is-flaky: true` with `--flaky`.

`<feat>` is a quid or hero-relative path to a doc core knows as a feat. A hero with no `gate` kind is refused. It prints the gate doc's path and the command that runs it.
