# Note

Legacy's `note` (its command doc `6274f51e`). The gist is the words given, joined by spaces. A first word ending in `:` names the note's kind, else it is a `memo`; the kind must be one the hero has.

The note is `kb/<quid>.md`, named by the gist slugged plus the id's last six hex digits, titled by the slug half, or by `--title`. `--body -` reads stdin, and `--body <file>` a file, as the text under the title.

`--scope <repo>` names the registered repo it is about, by quid or exact name; without it, the repo the config's `bridge:` key names, said on stdout. That repo doc links the note, rel `<kind>.note`. Legacy took `--scope` more than once; one is taken here.

The note and the repo doc it links from are one commit.
