# Find repo

The repo doc in `.nosedive/repos` whose id is the quid given, or whose name is the name given; a name two docs share is refused, naming both quids.

`checkoutAt` gives a repo's checkout at a ref: a missing one is made by core's hydrate-repo, read-only at trunk, then detached at the ref, fetched from origin when the cache lacks it. An existing one is left where it is, saying when it is not at the ref.
