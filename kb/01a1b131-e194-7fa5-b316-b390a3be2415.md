# Held dive

The dive the hero's branch names as work's dive branch, `nosedive/<holder token>/<dive id>`: a doc of work's dive kind in the hero, its `meta.feat` and its scope entries keyed by registered repos, each with its `ref`. A hero on any other branch holds none. A dive that is over, or whose `diver` carries another token, is refused, as work refuses it.

This repeats work's rule rather than importing work's dive-on-deck, so the cape builds and tests against core alone; it changes when work's dive branches do.
