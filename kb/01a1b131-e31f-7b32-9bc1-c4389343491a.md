# Run gates

Runs gates in order with legacy's ctx, as [test](01a1b129-c081-79e5-abdc-c058f6a359a4.md) describes: each in its own node process, its output inherited so it streams, `resolve` answered over IPC, and drained after `run` as legacy's runner was, exiting after 30 seconds of silence (`NOSEDIVE_GATE_IDLE_MS`). A missing script fails its gate. After the summary it throws when a gate failed whose link is not flaky, which is how test exits 1.
