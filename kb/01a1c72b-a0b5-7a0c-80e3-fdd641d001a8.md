# Record dive

Every change an action makes to a dive goes through it: the meta it sets (null clears a field; the rest of the meta is left as it is), the state its link moves to on every doc that holds one (the action's: jumped, packed, landed or bailed), a `## <timestamp> <label>` section appended (labels `jumped`, `packed`, `landed`, `bailed`; timestamp ISO 8601 UTC with `Z`, as pass --turn heads its own) with the lines it is given, and any other hero docs it is handed, with the docs whose link it moved, all committed to the hero in one commit, `<action>(<dive name>): <summary>`, the loop's command first and the dive it acted on, whatever feat the hero holds (loop-command-subjects), which ends with the nosedive co-author trailer (see commit-message) like every commit the loop makes in the hero. It is given the core version for that trailer. Dives written with the old `## Jumped <timestamp>` headings stay as they are; nothing in the loop reads sections by heading but jump, which reads a `migrated` one (see jump). Pushing is the action's: each puts its commit on the hero's trunk on origin.
